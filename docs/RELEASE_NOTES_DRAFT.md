# Proposed Tag: v1.1.1

This release resolves several chat UI formatting and retrieval issues, substantially improves claim extraction coverage (including positioning and superiority claims), and tightens the auditor's strictness to prevent "supported" verdicts on claims that lack underlying experimental evidence. Additionally, we have restored secretless CI by moving matcher gold-set verification to a frozen-fixture pattern, and improved eval accuracy by ensuring transient failures result in a SKIPPED status rather than artificially inflating failure rates.
