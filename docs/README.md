# Prism Docs

- `FINDINGS.md`: Summary of eval numbers, experimental results, and root causes. Read first.
- `decisions.md`: Historical log of technical and product decisions. Read to understand past choices.
- `deployment-and-environment-architecture.md`: Architecture of the Container Apps and Azure services. Read when configuring or deploying the infrastructure.
- `eval-harness-design.md`: Design and architecture of the evaluation harness. Read before tuning prompts or evaluating changes.
- `extraction-audit-grounding-architecture.md`: Pipeline design for claim extraction and grounding. Read to understand the core engine flow.
- `mcp-integration-plan.md`: Scope and tenancy plan for future MCP integration. Read if considering exposing Prism as an MCP server.
- `observability-and-cost-plan.md`: Discovery findings and plan for observability and cost protection. Read before modifying telemetry or budget constraints.
- `pipeline_architecture_review_2026-09-05.md`: Review of the extraction and grounding pipeline stability. Read to understand historical pipeline issues.
- `PRISM_STATUS.md`: Current state of the repository, eval chain, and in-flight work. Read to get up to speed on active tasks.
- `PRODUCT_BRIEF.md`: High-level product vision and requirements. Read for project context.
- `RUNBOOK.md`: Operational commands and procedures for running the stack locally and troubleshooting. Read when running Prism.
- `design/`: UI designs, application inventory, and design system specs. Review when changing the frontend.
- `diagrams/`: Architecture and UI images (PNG) used in the README.
- `evals/`: Ground-truth benchmark JSON files and fixtures for the eval harness.
- `experiments/`: Experiment marks and pilot test records.
- `research_papers/`: Golden PDFs used for evaluation and testing.
