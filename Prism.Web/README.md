# Prism.Web

React 19 + TypeScript + Vite + Tailwind UI: paper upload, Claim-Support Matrix, paper-scoped chat.

- Run: started by Prism.AppHost with the rest of the app (root README, Quick start).
- Checks: `npm run build` and `npm run lint`.
- Design tokens: `tailwind.config.ts`, documented in `docs/design/`.
